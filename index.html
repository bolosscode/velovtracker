Source de données

L'app utilise le WFS Open Data Grand Lyon — aucune clé API nécessaire.
En Live, les données sont appelées directement depuis le navigateur (rafraîchissement en temps réel).
Pour l'historique et la heatmap, le fichier data/latest.json collecté par GitHub Actions est utilisé.

→ data.grandlyon.com — jeu de données Vélo'v ↗

Architecture

Collecte : collect.py via GitHub Actions toutes les 10 min → appel WFS Grand Lyon.
Stockage : data/latest.json (snapshot courant) + data/history/YYYY-MM-DD.json (tableau de snapshots par jour).
Hébergement : GitHub Pages depuis la racine de la branche main.
